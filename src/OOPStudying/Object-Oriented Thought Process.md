1- What is an object
    entity that contains both properties and behavior
2- What is the difference between OO and Procedural or Structured design
    - in OO the data and behavior are tightly coupled, yet in the others they are separated
    - u can control data access in OO, yet not in the others, since global variables can be accessed anywhere by function, that goes for the functions/behaviors also, like u can control access in OO to both data and behaviors 
3- What is encapsulation
    - its the process of combining both attributes and methods in the same object

    NOTE: The object attributes are called the state of the object
